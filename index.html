동기화 이 기기만

Firebase를 연결하면 다른 기기와 같은 대화를 봅니다.

    모든 설정값은 이 브라우저의 localStorage에만 저장되고 서버로 보내지 않습니다.

    AI별 API 키 BYOK

    키를 넣은 AI만 실제 답변을 합니다. 넣지 않은 AI는 예시(시뮬레이션) 답변으로 동작합니다.

    키 보관 주의

    브라우저에 넣은 키는 이 기기에서만 쓰입니다. 공용 PC에서는 쓰지 말고, 노출이 걱정되면 아래 브릿지 탭의 Cloudflare Worker 방식을 권장합니다.

    Firebase Firestore 여러 기기 동기화

    Firebase 콘솔 → 프로젝트 설정 → 내 앱(웹)에서 firebaseConfig를 복사해 붙여넣으세요. 3초 안에 연결되어 안건과 대화가 실시간으로 동기화됩니다.

    컬렉션: aiOfficeTopics, aiOfficeMessages · Firestore 규칙은 README의 예시를 참고하세요.

    Cloudflare Worker 브릿지 키를 서버에 두기

    Worker 주소를 넣으면 API 키가 브라우저에 없어도 AI가 답합니다. 저장소에 들어 있는 cloudflare-worker.js와 CLOUDFLARE_SETUP.md를 참고해 5분이면 배포됩니다.

    데이터

    안건과 대화는 이 브라우저에 저장됩니다. 백업해 두면 다른 기기로 옮길 수 있습니다.
